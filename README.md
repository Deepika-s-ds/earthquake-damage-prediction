\# Earthquake Damage Grade Prediction



\## Project Overview



This project uses machine learning to predict earthquake-related building damage grades using structural, geographic, and demographic features.



The objective is to analyse building characteristics and develop a predictive model that can support earthquake damage assessment and risk analysis.



\## Project Workflow



\* Data loading and initial inspection

\* Data cleaning and quality assessment

\* Exploratory data analysis

\* Feature engineering

\* Categorical feature encoding

\* Model development

\* Model evaluation

\* Feature-importance analysis

\* Business interpretation



\## Technologies Used

\* Matplotlib
